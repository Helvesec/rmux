# Protocol capability and error reference

Generated by `cargo run -p rmux-proto --example protocol_registry`.

Capabilities are matched by exact id. Each caller chooses Required or Optional:
a missing Required id returns UnsupportedCapability, even when a fallback exists.
Optional absence returns the registered fallback or Unavailable; the caller decides
whether to use that fallback. Unknown advertised ids are Available; unknown absent
ids are Unavailable when optional and errors when required. No fallback is automatic.

Advertisement is build-dependent: Baseline is always included, Web only with browser
sharing enabled, and Retired never. Registry order preserves the published inventory.
Advertised negotiation needs no extra opt-in; RequiredOnConnection needs an explicit
handshake on that connection; RequiredPerRequest uses an embedded handshake;
AttachOptIn echoes the id in the attach request. Lifetime describes negotiated
permission, not resource TTL. Cached inventories are discarded on reconnect.

Error codes are local, payload-free projections of RmuxError. They add no wire fields.
The numeric column is the existing bincode discriminant; descriptions come from
the same definitions as the serialized variants. Error display messages are unchanged.

| Code | Bincode discriminant | Meaning |
|---|---|---|
| `empty_session_name` | 0 | A session name was empty. |
| `invalid_session_name_character` | 1 | A session name contained `:` or `.`. |
| `invalid_target` | 2 | A target string failed exact detached parsing. |
| `unknown_command` | 3 | An unsupported public command name was requested. |
| `duplicate_session` | 4 | A session name collided with an existing session. |
| `session_not_found` | 5 | A session target did not resolve. |
| `server` | 6 | The server encountered an unexpected runtime failure. |
| `message` | 7 | A command surfaced an exact tmux-compatible user-facing error. |
| `invalid_set_option` | 8 | A `set-option` request violated the supported contract. |
| `frame_too_large` | 9 | A codec frame claimed a payload larger than the configured maximum. |
| `empty_frame` | 10 | A codec frame announced an empty payload. |
| `bad_frame_magic` | 11 | A frame did not start with the RMUX frame magic byte. |
| `unsupported_wire_version` | 12 | A frame used a wire version this build does not support. |
| `unsupported_capability` | 13 | A capability required by the caller is not supported by the daemon. |
| `incomplete_frame` | 14 | A full frame was requested but the buffer stopped early. |
| `encode` | 15 | Bincode encoding failed. |
| `decode` | 16 | Bincode decoding failed. |
| `pane_not_found` | 17 | A stable pane id did not resolve in the addressed session. |
| `process_still_running` | 18 | A pane still has a running process and replacement was not requested. |
| `spawn_failed` | 19 | A daemon-side process spawn failed. |
| `owned_session_lease_lost` | 20 | A daemon-side owned-session lease was not found or no longer matches. |
